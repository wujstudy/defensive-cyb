## B24. Design and implement access control of your choice.

- Designed and implemented a simple Linux access control demonstration in Kali Linux  
- Created separate user accounts to represent manager and employee roles  
- Used a managers group to demonstrate role-based access control (RBAC)  
- Configured file ownership and permissions using chown and chmod  
- Allowed the manager account to access the protected payroll file while denying access to the employee account  
- Demonstrated authentication, authorisation, least privilege, and Linux file permission enforcement
