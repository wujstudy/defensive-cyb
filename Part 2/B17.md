## B17. Implement one of the current state-of-the-art solutions and evaluate it.

- Implemented a simple SOC-style monitoring workflow using Kali Linux, Nmap, and Python  
- Used Nmap to scan and collect network and service information from the local system  
- Created a Python script to automatically analyse scan results and generate SOC-style alerts  
- In this test, no risky open services were detected on the scanned host  
- The automation reduced the need for manual review and demonstrated how SOC systems can improve monitoring efficiency  
- Limitation: the script only checked predefined ports and could not perform advanced behavioural or threat analysis
