## A2. Discover security concepts used in public space

- **Concept:** Authentication + Authorisation + Enforcement Mechanism

- **Authentication:**
  - Verifies a user’s identity before granting access
  - Often uses simple credentials or physical verification
  - (E.g. Entering a PIN when using an ATM or tapping a transport card)

- **Authorisation:**
  - Determines what actions a user is allowed to perform
  - Based on user role or permissions
  - (E.g. Only authorised personnel can access restricted airport or staff-only areas)

- **Enforcement Mechanism:**
  - Physical and digital controls used to enforce access rules
  - Prevents unauthorised entry or misuse
  - (E.g. Barriers, ticket gates, security guards/community watch)
