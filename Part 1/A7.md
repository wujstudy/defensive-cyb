## A7. Discover cryptography used in modern networks

- **Encryption:**
  - Converting data into ciphertext, preventing attackers from reading intercepted information
  - Modern networks use both asymmetric and symmetric cryptography together (asymmetric encryption is used first to securely exchange keys, and symmetric encryption is then used to efficiently encrypt the actual data)
  - This is commonly implemented in protocols such as TLS, which secures most internet communication
  - Provides key security properties including confidentiality, integrity, and authentication
  - (E.g. When accessing a website using HTTPS, TLS uses RSA to exchange keys and AES to encrypt data)
