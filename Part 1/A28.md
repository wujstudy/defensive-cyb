## A28. Implement a security solution and publish it on GitHub

- https://github.com/wujstudy/defensive-cyb/blob/main/password%20checker

- Chose to create a password strength checker because weak passwords are a common security risk (and because of a recent reddit post I had seen, I also realised that most ppl don’t understand the importance of strong passwords)
- Helps users create stronger, more secure passwords
- Improves confidentiality by protecting accounts from unauthorised access
- Supports authentication as passwords verify user identity
- Simple and practical to implement in Python
- Easy to explain and demonstrate as a cybersecurity solution
