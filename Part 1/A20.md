## A20. Participate in a discussion with friends about a cybersecurity event

- Discussed the Optus data breach with friends
- Talked about how sensitive information such as names and IDs were exposed (Confidentiality)
- Discussed how leaked data can be used for scams or fraud if misused (Integrity risk)
- Identified that the breach was caused by poor security practices, such as an exposed API
- Suggested improvements such as stronger access controls and better system protection to prevent unauthorised access
