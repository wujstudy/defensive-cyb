## A13. Discover 5 unique online security tools

- **a. Firewall:**
  - Confidentiality (blocks unauthorised access)
  - Integrity (filters traffic)

- **b. Antivirus software:**
  - Integrity (prevents malware)
  - Availability (keeps system usable)

- **c. Intrusion Detection System (IDS):**
  - Integrity (detects suspicious activity)

- **d. VPN:**
  - Confidentiality (encrypts data in transit)

- **e. Password manager:**
  - Confidentiality (protects stored credentials)
