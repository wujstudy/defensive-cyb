## B29. Find a CVE in this year and fix it using three different generative AI systems, comparing the consistency.

- Used ChatGPT, DeepSeek, and Gemini  
- CVE-2024-3094 was a backdoor vulnerability affecting XZ Utils, a Linux compression utility  
- The vulnerability added malicious code into certain XZ Utils versions and could allow remote code execution through SSH services  
- The incident highlighted software supply chain security risks and importance of code review and package verification  
- Common recommendations included downgrading affected versions, patching systems, and verifying trusted software sources  

Reference:  
https://nvd.nist.gov/vuln/detail/CVE-2024-3094
