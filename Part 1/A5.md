## A5. Discover cryptographic implementation used online

- **Asymmetric Key Cryptography:**
  - Public key is shared, private key is kept secret
  - Data encrypted with the public key can only be decrypted with the private key
  - Used in HTTPS/TLS handshake to securely exchange a symmetric key
  - After the handshake, symmetric encryption is used for faster communication
  - Also used for authentication (e.g. digital signatures verify sender identity)
