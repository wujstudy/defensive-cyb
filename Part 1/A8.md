## A8. Discover cryptography used in Internet of Things (IoT) devices

- **Hashing:**
  - Hashing is a cryptographic technique that uses a one-way function to convert data into a fixed-size hash value
  - It is used to ensure data integrity by allowing systems to detect if data has been altered during transmission
  - Even a small change in the original data will produce a completely different hash value
  - IoT devices use hashing to verify that data sent between devices or to cloud servers has not been tampered with
  - This is important in IoT environments where devices automatically exchange data and require reliable verification
  - (E.g. A smart home device can use hashing to verify that sensor data has not been modified before being processed or stored)
