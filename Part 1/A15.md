## A15. Discover 5 recent security incidents

- **a. Data breach:**
  - Confidentiality compromised (unauthorised data access)
  - youX exposed 141GB of sensitive data, affecting over 600,000 users
  - Demonstrates how poor data security leads to large-scale exposure of personal information

- **b. Ransomware attack:**
  - Availability compromised (data locked), Integrity compromised
  - Interlock ransomware (2026) exploited a firewall vulnerability to gain access and deploy malware
  - Shows how unpatched vulnerabilities can allow attackers to encrypt systems and disrupt operations

- **c. Phishing attack:**
  - Confidentiality compromised (credentials stolen)
  - AI-driven phishing attacks in 2026 have increased significantly, including deepfake voice scams
  - Shows how attackers use social engineering and AI to trick users into revealing sensitive information

- **d. DDoS attack:**
  - Availability compromised (service unavailable)
  - Record-breaking DDoS attacks in 2026 exceeded 31 Tbps using IoT botnets like Aisuru
  - Shows how large-scale botnets can overwhelm systems and make services unavailable

- **e. Supply chain attack:**
  - Integrity compromised (software tampered)
  - Attackers compromised the Axios npm package to distribute malware to millions of users
  - Shows how trusted software dependencies can be exploited to spread malicious code
