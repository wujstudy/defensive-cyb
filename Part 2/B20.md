## B20. Enhance the security of a GitHub project.

- Reviewed an open-source GitHub project and identified risks relating to unsanitised user input  
- Implemented a Python input sanitisation function to restrict potentially malicious characters in usernames  
- Used regular expressions to validate and clean user input before processing data  
- Improved the project’s security by reducing the risk of injection-based attacks through safer input handling  
- Used GitHub workflows including forking repositories, editing source code, and committing security-related changes
