## B1. Discover 5 unique weak/vulnerable security implementations.

### a. Default passwords
- Some systems still allow short or easily guessable passwords  
- Weak passwords increase risk of brute-force and credential stuffing attacks  
- (E.g. Users setting passwords such as “Password123” or reusing the same password across accounts)

### b. Reusing Default Credentials
- Many routers, IoT devices, and systems still use default usernames and passwords  
- Attackers commonly scan for devices using publicly known default credentials  
- (E.g. A router still using “admin/admin” as its login credentials)

### c. Delayed Software Patching
- Unpatched software remains vulnerable to publicly known CVEs and exploits  
- Attackers often target outdated systems because exploits are already available online  
- (E.g. Running an outdated Windows system vulnerable to EternalBlue exploits)

### d. Storing Sensitive Data Without Encryption
- If attackers gain database access, exposed information can be read directly without needing decryption  
- Weak or missing encryption significantly increases the impact of data breaches  
- (E.g. A database storing customer passwords in plaintext)

### e. Excessive User Permissions
- Users are sometimes given more permissions than necessary for convenience  
- Violates the principle of least privilege by allowing unnecessary access to systems  
- (E.g. Regular employees having administrator access to business systems)
