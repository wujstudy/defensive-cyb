## A16. Discover 3 local security incidents

- **a. Medibank breach:**
  - Confidentiality compromised (customer data leaked)
  - Hackers accessed and leaked sensitive customer data, including medical records and personal information
  - Shows how healthcare data breaches can expose highly sensitive information and lead to privacy risks
  - Issue: Poor security controls allowed unauthorised access to sensitive health data
  - Mitigation: Implement stronger access controls, encryption of sensitive data, and regular security monitoring

- **b. Optus breach:**
  - Confidentiality compromised (personal information exposed)
  - Attackers accessed customer data such as names, addresses, and identification details through an exposed API
  - Highlights how misconfigured systems can lead to large-scale data exposure
  - Issue: Unsecured or improperly configured API allowed public access to private data
  - Mitigation: Secure APIs with authentication, restrict access, and perform regular vulnerability testing

- **c. Latitude Financial breach:**
  - Confidentiality compromised (identity data stolen)
  - Identity documents such as driver’s licences and passports were stolen from customers
  - Demonstrates how stolen identity data can increase risk of identity theft and fraud
  - Issue: Sensitive identity data was stored without sufficient protection
  - Mitigation: Minimise data storage, encrypt stored data, and apply strict data retention policies
