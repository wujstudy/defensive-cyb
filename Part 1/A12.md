## A12. Discover 5 unique offline security tools

- **a. KeePass:**
  - Confidentiality (stores passwords in encrypted local files)
  - Authentication (protects access with a master password)

- **b. VeraCrypt:**
  - Confidentiality (encrypts files, partitions, and drives)
  - Integrity (prevents unauthorised data access or modification)

- **c. Wireshark:**
  - Integrity (analyses network traffic for suspicious activity)
  - Availability (used to troubleshoot network issues)

- **d. Cuckoo Sandbox:**
  - Integrity (analyses malware in a controlled environment)
  - Confidentiality (prevents malicious files from affecting real systems)

- **e. Nmap:**
  - Integrity (identifies vulnerabilities and network services)
  - Availability (helps detect misconfigurations that could affect systems)
