## B25. Design and implement a threat intelligence module of your choice.

- Created a simple threat intelligence module using Python in Kali Linux  
- Simulated threat feed containing malicious IP addresses, phishing domains, and malware-related indicators  
- Classified threats using severity levels including Low, Medium, High, and Critical  
- Python script automatically detects high-risk threats and generates alerts  
- Limitation: the module used simulated data and did not connect to live threat intelligence feeds
