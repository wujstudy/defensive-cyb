## A17. Discover 10 different types of locks in use

- **a. Deadbolt lock:**
  - Confidentiality (prevents unauthorised entry)
  - Enforcement

- **b. Padlock:**
  - Confidentiality (secures items)
  - Enforcement

- **c. Combination lock:**
  - Authentication (requires code)
  - Confidentiality

- **d. Smart lock:**
  - Authentication (digital access)
  - Confidentiality

- **e. Biometric lock:**
  - Authentication (fingerprint/face)
  - Confidentiality

- **f. Keycard lock:**
  - Authentication (card-based access)
  - Confidentiality

- **g. Lever handle lock:**
  - Confidentiality (basic access control)
  - Enforcement

- **h. Cylinder lock:**
  - Confidentiality (restricts entry)
  - Enforcement

- **i. Electronic keypad lock:**
  - Authentication (PIN-based)
  - Confidentiality

- **j. Magnetic lock:**
  - Enforcement (electromagnetic locking)
  - Confidentiality
